# قرارات تجهيز البيانات

## المصادر

توضع النسخ الأصلية من `train.csv` و`test.csv` وملفي المراجع في `data/raw/`. لا تُعدّل هذه الملفات ولا تُحذف صفوف منها. تتضمن نسخة المشروع المنشورة هذه الملفات بعد تأكيد السماح بإعادة توزيعها.

## التحقق والتنظيف

- التحقق من وجود الأعمدة المطلوبة قبل متابعة التحليل.
- رفض الملف برسالة واضحة إذا وُجدت قيم مفقودة في مفاتيح الإدخال أو أهداف تدريب مفقودة/سالبة.
- التحقق من تفرد `id` ومفتاح `(week, center_id, meal_id)` في كل من التدريب والاختبار.
- التحقق من تطابق المراكز والوجبات مع جداولها المرجعية، ثم دمجها بعلاقة many-to-one.
- عدم حذف سجلات أو تعويض قيم؛ الفحص الأولي وجد بيانات مكتملة، لذا الحذف أو التعويض غير مبرر.
- حساب `discount_amount = base_price - checkout_price` و`discount_rate = discount_amount / base_price`. النسبة السالبة تبقى كما هي إن كان سعر الشراء أعلى من السعر الأساسي؛ لا نفترض أن كل فرق سعر خصم.
- تقدير الإيراد كمؤشر وصفي فقط: `num_orders × checkout_price`. لا يُفسر كربح لعدم توفر التكاليف.
- اعتبار `test.csv` تنبؤاً لاحقاً للأسابيع 146–155، فلا يستخدم لاستخلاص نتائج ذات هدف معروف.

## إعادة الإنتاج

من مجلد المشروع شغّل:

```powershell
python src\food_demand_analysis.py
```

يُنتج سجل الجودة والجداول الإحصائية والتقرير والرسوم داخل `reports/`. تشغيل النماذج والتنبؤ الاختياري:

```powershell
python src\food_demand_analysis.py --train-models
```
