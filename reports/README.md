# مخرجات المشروع

يُنشئ `src/food_demand_analysis.py` تقرير العميل (`client_report.md`)، مخطط العرض (`presentation.md`)، وملخصات الطلب الأسبوعي والفئات والمطابخ والمراكز والوجبات، واختبارات الترويج والرسوم البيانية داخل هذا المجلد.

شغّل `python src\create_presentation.py` لإنشاء العرض `presentation.pptx` بعد إنشاء الرسوم.

شغّل خيار `--train-models` لإضافة مقارنة النماذج و`submission.csv`.
